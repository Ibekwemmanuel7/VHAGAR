T1 temporal-anomaly: real 3.9um cube pull + matched-FAR lead-time eval vs GOES FDC

The heavy piece left for the temporal differentiator was its real input and a real
comparison. Both are now built and unit-tested offline; only the S3 pull (network) and
optional torch training are the user's to run.

archive/temporal_cube.py
- pull_bt_cube: read GOES ABI L2 CMIP band 7 (3.9um) from public S3, crop each 5-min
  frame to a small bbox, stack onto the one stationary ABI fixed grid into a [T,H,W] cube
  that carries its own UTC timestamps + lat/lon/view-zenith. Grid alignment asserted
  (shape + corner navigation); a mismatched frame is dropped, never misaligned. NaN
  (cloud/fill/saturation) stays NaN so nodata never enters the baseline. Concurrent reads,
  pure assemble_cube. save/load_bt_cube.
- solar_zenith_cube: per-frame solar zenith covariate (3.9um carries daytime solar
  reflectance) via physics.geometry.solar_position.
- fdc_first_detection_grid: map FDC parquet detections in the cube's bbox/window to the
  nearest cube pixel (<=3km reject), earliest frame index per pixel.

eval/t1_temporal.py
- HourlyBaselineForecaster: NaN-safe per-pixel per-hour-bin mean BT, the on-the-fly
  counterpart of DiurnalClimatology. A real cube's NaNs rule out the harmonic lstsq of
  DiurnalForecaster; this is the same diurnal-baseline idea that tolerates holes.
- real_lead_experiment: residual threshold calibrated to matched FAR on the fire-free
  pixels; per-fire-pixel lead = FDC first-detection index - first residual crossing.
  Positive = the residual detector beat FDC at equal false-alarm rate. The synthetic
  +70min demo, re-run on real observations.

CLI: t1-pull-cube (run the pull), t1-temporal-real (fit baseline, time vs FDC).

Tests (4 new, offline): assemble_cube drops a mismatched-grid frame and restores order;
solar zenith ~small at local noon; hourly baseline is NaN-safe and removes the diurnal
cycle; real_lead_experiment shows the residual leading a deliberately late FDC. End-to-end
smoke on a synthetic cube + fake FDC parquet: residual leads +50 min at FAR 0.01.

Learned upgrade is drop-in: swap TemporalAnomalyNet residuals into real_lead_experiment;
the matched-FAR lead-time protocol is unchanged. docs/12 "Running it on real GOES data
(the pull)"; PROGRESS updated. Full suite green, ruff clean.
